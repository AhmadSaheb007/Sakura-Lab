# Sakura Lab

A frontend-only Japanese N5 study prototype with hiragana and katakana charts,
English and Bangla pronunciation toggles, and ten everyday Japanese phrases.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run lint` and
`npm run build` to check the app before deploying.

Kana and phrase content lives in JSON files under `app/data/`. The application
uses the Next.js App Router and can be deployed to Netlify with its Next.js
runtime support.
